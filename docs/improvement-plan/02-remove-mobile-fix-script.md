# Шаг 2: Убрать `_mobile_fix.js` — скрипт-патчер в корне репозитория

## Проблема

В корне репозитория лежит `_mobile_fix.js` — Node-скрипт на ~200 строк,
который **регэксп-заменами** правит `app/store/[slug]/page.tsx`: меняет
`flex` на `flex-col lg:flex-row`, вырезает `BannerSlider`, подгоняет
паддинги и т.п. (см. `_mobile_fix.js:1-202`).

Это не часть сборки/CI — обычный одноразовый скрипт, который кто-то запустил
руками и забыл удалить. Проблемы такого подхода:

- Изменения в `page.tsx` де-факто были сделаны "вслепую" через `string.replace`,
  а не осознанным редактированием — высокий риск тихо сломать соседний код,
  если строка совпала не в том месте.
- Скрипт не идемпотентен по содержимому — если кто-то поправит `page.tsx`
  вручную, при повторном запуске скрипт либо ничего не сделает (`SKIP`), либо
  применится не туда.
- Он вводит в заблуждение новых разработчиков ("зачем в корне репо лежит
  рандомный JS-файл, который правит один конкретный компонент?").
- Сам факт его существования — симптом того, что мобильная адаптивность
  не закладывалась сразу, а чинилась постфактум патчами.

## Почему это важно

Гигиена репозитория и доверие к git history: правки UI должны быть видны как
обычный diff в обычном коммите, а не как результат запуска скрипта, который
никто больше не увидит.

## Что сделать

1. Открыть `app/store/[slug]/page.tsx` и для каждого из 9 фиксов в
   `_mobile_fix.js` убедиться, что изменение **уже применено** (большая
   часть, судя по `git log`, уже вошла через коммит `2d9500a`).
2. Если какой-то фикс из скрипта ещё не применён — применить его руками через
   обычный `Edit`, не через скрипт.
3. Удалить `_mobile_fix.js` из репозитория.
4. Добавить в `CLAUDE.md`/`AGENTS.md` короткое правило: UI/responsive-правки
   делаются прямыми правками файлов, разовые скрипты-патчеры в репозиторий не
   коммитятся (можно держать в `/tmp` или scratchpad, если вообще нужны).

## Критерий готовности (DoD)

- [ ] `_mobile_fix.js` удалён из репозитория.
- [ ] Все 9 фиксов из скрипта подтверждённо присутствуют в актуальном
      `app/store/[slug]/page.tsx` (вручную сверено).
- [ ] В репозитории не осталось других файлов того же рода (проверить
      `git status`/корень репо на одноразовые `*_fix.js`, `*_patch.js` и т.п.).
