# GoldenCart — план улучшений (обзор)

Этот план — результат аудита логики, архитектуры и дизайна проекта на 2026-06-30.
Каждый шаг — отдельный файл, шаги отсортированы по приоритету: сначала то, что
ломает бизнес-логику прямо сейчас, потом архитектурный долг, потом UX/дизайн.

Не обязательно делать всё подряд одним PR на шаг — но **не пропускайте порядок**:
часть поздних шагов опирается на то, что сделано в ранних (например, шаг 04
про типобезопасность данных проще делать после шага 03 про схему БД).

## Как пользоваться этим планом

Каждый файл шага содержит:
- **Проблема** — что именно не так, с точными ссылками на файл/строку.
- **Почему это важно** — последствия, если не чинить.
- **Что сделать** — конкретные действия.
- **Критерий готовности (DoD)** — как понять, что шаг закрыт.

Берите шаги по одному, делайте отдельный PR/коммит на шаг — так проще ревьюить
и откатывать при необходимости.
